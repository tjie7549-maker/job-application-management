# Job Application Management

一个用于管理中文求职投递进度的 Codex skill。

它将招聘页面、邮件、截图或文字说明整理为可复盘的本地投递表，并维护投递、筛选、测评、面试和 Offer 状态。

## 能做什么

- 从招聘链接、截图或文字中提取公司、岗位、Base、渠道、投递时间和当前流程
- 维护本地 `application-tracker.html` 投递表
- 统计投递总数及各流程状态
- 支持一面、二面、三面、四面、HR 面与 Offer
- 记录用户手动选择的想去程度：海投、有点意思、想去
- 支持公司搜索、手动新增、修改和删除投递记录
- 按想去程度、流程进展自动排序；已结束记录置底

## 安装

将本仓库中的 `SKILL.md` 放入 Codex skills 目录，例如：

```text
C:\Users\<你的用户名>\.codex\skills\offer\SKILL.md
```

然后重新打开 Codex，或在新任务中调用：

```text
$offer
```

## 使用方式

直接发送招聘链接、截图或简短文字即可。例如：

```text
$offer
兆易创新 合肥
嵌入式软件工程师
```

或：

```text
$offer
https://example.com/personal/deliveryRecord
公司：某科技
Base：深圳
```

也可以发送流程更新：

```text
某公司进入二面
某公司挂了
某公司拿到 Offer
```

## 记录规则

- 企业性质默认记为“私企”，除非用户明确说明。
- Base 未提供时留空，不根据总部或岗位名称猜测。
- 同一公司、同一岗位只保留一条最新流程记录。
- “流程进行中”本身不代表进入筛选或面试。
- 明确显示测评环节时记为“测评中”。
- 面试轮次未知时记为“面试（待细分）”。
- 已结束状态用红色标识，Offer 用绿色标识。

## 隐私与安全

此 skill 不记录或公开：

- 密码、验证码、MFA 信息
- 身份证件信息
- 申请编号或带个人追踪参数的链接
- 用户真实投递记录、简历或其他求职材料

登录、验证码、CAPTCHA 和最终提交操作始终由用户本人完成。

## 投递表功能

生成或维护的 HTML 投递表支持：

- 顶部公司搜索
- 状态汇总卡
- 想去程度和当前状态下拉修改
- 手动新增、修改、删除记录
- 自动排序与分组展示

投递表生成的是本地 HTML 文件（通常为 `application-tracker.html`），不需要部署服务器。首次在浏览器打开后，可以将该文件页面加入浏览器收藏夹；之后直接从收藏夹打开，即可继续查看和维护同一份投递表。
